# Руководство по получению Root на Яндекс Станции Мини 1 (YNDX-0004)

Данное руководство подробно описывает процесс разблокировки и получения постоянного root-доступа на **Яндекс Станции Мини 1-го поколения** (модель `YNDX-0004`, процессор **Amlogic A113X**) без пайки и разборки корпуса.

---

## 📌 1. Требования и оборудование

1. **Колонка:** Яндекс Станция Мини 1 (`YNDX-0004`). На дне колонки должна быть надпись `Модель: YNDX-0004`. Оснащена датчиком жестов сверху и портом Type-C сзади.
2. **Кабель Type-C:** качественный кабель **с линиями передачи данных** (data-кабель от современного смартфона). Комплектный кабель от блока питания Яндекса передаёт только питание и для прошивки не подходит!
3. **Компьютер:** под управлением Windows 10/11 x64 (рекомендуется) либо Linux с установленным `libusb`.
4. **Утилита StationMiniRoot:** версия `v0.3.15` или новее (в ней снято ограничение по SHA-256 прошивок и поддерживаются даже самые свежие апдейты прошивки Яндекса).

---

## ⚙️ 2. Принцип работы эксплойта Amlogic A113X

Процессор Amlogic A113X при подключении по USB без подачи основного питания входит в сервисный режим загрузчика (BootROM режим с USB ID `1B8E:C003`).

Утилита **StationMiniRoot**:
1. Перехватывает колонку в режиме Amlogic USB DNL.
2. Загружает в оперативную память временный Linux-загрузчик (U-Boot + initramfs).
3. Вычитывает полный системный раздел (`/dev/system`, 80 МБ) в память компьютера и сохраняет локальный бэкап.
4. Разбирает файловую систему UBIFS (через WSL в Windows или нативный Linux).
5. Внедряет постоянный root ADB:
   - Добавляет открытый ключ вашего компьютера (`adbkey.pub`) в `/root/.android/authorized_keys` и `/data/`.
   - Включает службу `adbd` от пользователя `root` с доступом по USB и сети Wi-Fi (порт 5555).
   - Блокирует официальные обновления Яндекса (OTA), чтобы свежая прошивка не перезаписала root.
   - Развёртывает платформу `Alice Homebrew` в разделе `/data`.
6. Собирает модифицированный образ, записывает его обратно во флеш-память NAND и проверяет контрольную сумму.

## 🚀 3. Пошаговая инструкция получения Root

### Шаг 1. Подготовка софта (Windows)
1. Скачайте архив `StationMiniRoot-windows-x64.zip` (версия 0.3.15+).
2. Распакуйте архив в папку без пробелов и русских букв в пути, например:  
   `C:\StationMiniRoot\`
3. Запустите `StationMiniRoot.exe` (от имени администратора).
4. В окне программы нажмите кнопку **«Установить все зависимости»**:
   - Утилита установит необходимые USB-драйверы Amlogic / WinUSB (подтвердите запрос Windows UAC).
   - Подготовит подсистему WSL для распаковки файловой системы UBIFS.
5. Дождитесь надписи «Зависимости успешно установлены».

### Шаг 2. Подключение колонки к ПК
1. **Отключите блок питания** от Станции (колонка должна быть полностью обесточена).
2. Подключите кабель Type-C к Станции.
3. Второй конец кабеля вставьте напрямую в порт USB 3.0 / 2.0 на материнской плате компьютера (не используйте переходники и USB-хабы).
4. **Кнопки зажимать не требуется**: как только колонка получит питание по USB от ПК, процессор автоматически определится в режиме Amlogic DNL (`1B8E:C003`), и индикатор статуса в программе станет зелёным.

### Шаг 3. Запуск процесса рутирования
1. Нажмите кнопку **«Установить root»** в окне StationMiniRoot.
2. Процесс займёт 3–5 минут и пройдёт следующие фазы:
   - `Reading partition system...` — создание полного резервного бэкапа заводской прошивки (сохраняется в `%LOCALAPPDATA%\StationMiniRoot\work\dumps\`).
   - `Unpacking UBIFS...` — распаковка системных файлов.
   - `Patching system...` — добавление `adbd`, ключа авторизации, фиксация OTA.
   - `Flashing system...` — запись модифицированного раздела обратно в память колонки.
   - `Verifying SHA-256...` — проверка целостности записи.
   - `Rebooting...` — перезагрузка колонки в нормальный режим.

> ⚠️ **КРИТИЧЕСКИ ВАЖНО:** во время записи раздела (`Flashing system...`) **категорически запрещено** выдёргивать провод, выключать компьютер или закрывать программу!

### Шаг 4. Проверка Root и связи по ADB
1. После перезагрузки колонка издаст штатный звук включения и загорится фиолетовый/синий светодиод.
2. Откройте командную строку и выполните проверку:
   ```cmd
   adb devices
   ```
   Вы увидите список подключённых устройств:
   ```text
   List of devices attached
   FF98F0290D2693BB722DA956    device
   ```
3. Проверьте права root:
   ```cmd
   adb shell id
   ```
   Ответ должен быть:
   ```text
   uid=0(root) gid=0(root) groups=0(root)
   ```
   **Поздравляем! Ваша Яндекс Станция успешно рутирована с правами root!**

4. Узнайте IP-адрес колонки в вашей домашней сети:
   ```cmd
   adb shell "ip route get 1.1.1.1 | awk '{print $7}'"
   ```
   (Например: `192.168.1.105`). Теперь вы можете подключаться к колонке по воздуху без кабеля:
   ```cmd
   adb connect 192.168.1.105:5555
   ```

---

## 🔒 4. Сохранение и восстановление бэкапа

Оригинальный заводской дамп вашей колонки сохранён в директории:
`%LOCALAPPDATA%\StationMiniRoot\work\dumps\`

Если когда-либо потребуется вернуть колонку в полностью заводское состояние:
1. Подключите колонку по USB.
2. В программе выберите пункт **«Восстановить заводской бэкап»**.
3. Укажите сохранённый файл `system_backup.img`.
